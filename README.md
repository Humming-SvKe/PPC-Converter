# Perfect Portable Converter

Univerzální nástroj pro konverzi, úpravu a optimalizaci videí. PPC je plně portable aplikace, kterou stačí stáhnout, rozbalit a ihned používat bez instalace. Vhodné na USB, offline použití, automatické zpracování velkých dávek souborů, úpravu titulků, generování náhledů, export pro sociální sítě a další pokročilé funkce.

## Funkce

- Plná portabilita – žádná instalace, žádné zásahy do systému
- Podpora dávkového zpracování (batch)
- Správa souborů pomocí drag&drop a fronty
- Nastavení pro formáty, kodeky, rozlišení, limity platforem (Telegram, WhatsApp, Instagram…)
- Pokročilý editor náhledů (thumbnails), vodoznaky, styling
- Titulky: import, úpravy, synchronizace, převod, efekty
- Hard/soft embed, OCR, překlady titulků
- Export pro sociální sítě, device optimalizace
- Monitoring volného místa, hardware check
- Moderní uživatelské rozhraní (světlý/tmavý režim, jazykové mutace)
- Podpora offline režimu, provoz z USB

## Použití

1. Stáhněte ZIP balíček ze sekce „Code“ → „Download ZIP“.
2. Rozbalte jej do libovolné složky (ideálně na USB flash disk).
3. Spusťte PPC.exe nebo START.bat.
4. Vkládejte soubory, nastavte parametry a spusťte konverzi.
5. Výsledné soubory exportujte na disk nebo do cloudu.

## Poznámky

- PPC je vhodný pro běžné uživatele i profesionály.
- Není nutná žádná instalace ani administrátorská práva.
- Program neukládá žádné informace mimo svůj pracovní adresář.
